# Mindless Midi knowledge base

A map of this repository: what each part is for, how the parts connect, and
how to do the common jobs. Every concept file is markdown with YAML
frontmatter ([Open Knowledge Format](https://github.com/GoogleCloudPlatform/open-knowledge-format) v0.2),
so people and agents can both read it. Start with the overview.

- [Overview](./overview.md) - What Mindless Midi is, in one page, and where to go next
- [Repository map](./repo-map.md) - Every top-level directory and what lives in it
- [Apps](./apps/index.md) - The three front ends: Mindless Midi, Mighty Midi and the synthesis bench
- [Modules](./modules/index.md) - The TypeScript packages under `src/`, from music theory to the mix bus
- [Concepts](./concepts/index.md) - Ideas that cut across modules: seeds, styles, engines, gestures, sessions
- [Build and tooling](./build/index.md) - Bazel rules, build-time tools, samples, deployment, agent skills
- [Guides](./guides/index.md) - How to run, test, add or regenerate a style, render offline, deploy
- [Plans](./plans/index.md) - Design plans and their status
