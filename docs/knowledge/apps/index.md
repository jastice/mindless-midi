# Apps

Three static web pages built from the same arranger, corpora and engines.

- [Mindless Midi](./mindless-midi.md) - The main page: pick styles, press play, music forever
- [Mighty Midi](./mighty-midi.md) - Same music, performed and mixed for weight, with a light-block stage view
- [Synthesis bench](./bench.md) - Renders one score through every engine for loudness-matched A/B listening
